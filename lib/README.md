# Lib

Shared utilities, constants, validation, and chat streaming helpers.

| Path | Purpose |
|------|---------|
| `chat/parse-sse.ts` | SSE line parsing and stream consumption |
| `chat/stream-chat.ts` | `fetch` client for `/api/chat` |
| `validation/chat-messages.ts` | API request body type guard |
| `constants.ts` | API paths and OpenAI defaults |
| `constants/ui-copy.ts` | Spanish UI strings |
| `prompts.ts` | System prompt for OpenAI |
| `types.ts` | Shared TypeScript interfaces |
| `utils.ts` | `cn()` for Tailwind class merging |
